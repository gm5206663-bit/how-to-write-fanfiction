## Stage 0 — Choose your lane (rulings first, prose second)

Decide **before writing a word**:

| Decision | Question | Example (Soul Land) | Example (MCU) |
|---|---|---|---|
| **Era / branch** | Which part of source timeline? | Soul Land 2 (The Unrivaled Tang Sect era) | MCU Iron Man 1 (2008) |
| **Entry point** | Where does chapter 1 sit on canon spine? | Canon ch 62–64, with 4-year pre-canon butterfly | IM1 beats 1–4 |
| **Divergence policy** | How far follow canon before bending? | Follow canon by default; bend only when earned + logged | Follow film order, plural panels, camera goes where canon goes |
| **Relation to other fics** | Same universe as other serials, or separate? | Default: separate universe | Separate, but sibling project VARUN paused at Ch3 |
| **OC seed** | Martial soul / Talent / bloodline? | Grey Wolf innate 1 + Ledger System + 3.5x effective talent + Spirit Sea 850 + body 500kg | Stark Heir born 1996 Tony's son + Adaptation Talent + X-gene + psychic core breakthrough slumbers |
| **Talent law** | How does Talent work? | Adaptation Talent: capability never content, stimulus-priced hours burns ring-gambles, mind excluded studies normal speed, body-load compensation, resonance across all categories | MCU Eternal: gravity+kinetic, buffer+field ceilings hard, Talent never named embodied only |

Write these as **numbered rulings** in `foundation/OPEN_RULINGS.md`. Any ruling author hasn't answered = **drafting locked**. This is not bureaucracy — it's how you avoid rebuilding chapter 30 later. Foundation-stage is a stage, not failure to start — Seed of Creation scaffolded 4 rulings pending zero chapters until ruled, Second Heartbeat Tang San's twin brother foundation with butterfly registry and ripple rules before word of prose, Holy Spirit 4ch governed by NO-MISTAKE KIT.

## Stage 2 — Ore mining (advanced)

"Ore" is raw canon material gathered from primary text before drafting:

- Extract canon chapters this fic will consume; keep INDEX.txt of what's held and where from — receipts never edited never silently corrected — variance logged both readings held
- Convert wiki/secondary knowledge into dated notes — secondary sources are ore, never law — e.g., CANON_GROUND.md verified 2026-09-24 against multiple fan-translation sources and Soul Land Wiki (rank table cross-checked in three independent WebNovel auxiliary chapters; ring colors cross-checked in all of them)
- Record good lines: speech patterns, running jokes, physical tells, possession carding (base-form card, stack order, ring-orbit exposure — e.g., Golden Lion panel v4→v5). Style-match starts here, not at keyboard
- For MCU: consume film beats 1-15 staged scene-by-scene film order (ambush → cave → find → return → chest-swap → workshop rebirth complete → gala Everhart photographs) — receipts first, film order, plural canon-side panels
- For beast-POV: research soul beast not normal animal, even commonest thing is blue silver grass — dogs → spirit hounds, serpent → Black-Ravine Serpent rule SB-11
- **Never write from memory of source.** Memory is where canon drift is born. Check canon perfectly (standing instruction).

## Stage 3 — The chapter loop (advanced perfect edition)

Per chapter, without exception:

```
   ┌─────────────────────────────────────────────────────────┐
   │  1. ORE        read the canon chapters this fic consumes │
   │  2. DRAFT      write the chapter (panels, prose law)     │
   │  3. SELF-AUDIT check every law by hand, fix your own     │
   │  4. GATE       run the machine checks — must exit 0      │
   │  5. SYNC       update EVERY state file same-turn         │
   │  6. SHIP       commit + push, stamp the live edge        │
   └─────────────────────────────────────────────────────────┘
        ↑ repeat. small things become big things if you skip.
```

**Advanced loop details:**

1. **ORE** — read/re-read canon chapters this chapter consumes. List them in ledger. For dual-track (Lan Shen V2): canon runs on page complete unskipped in Wulin's own close-third, OC parallel same clock same streets, butterfly only logged when tracks make contact on page. For MCU dual-track: canon runs on page complete unskipped in film order from plural canon-side panels P12+P12-AMENDMENT camera law P13 film order P14 plural panels, OC braided around with absolute canon ownership, T-registry.

2. **DRAFT** — write chapter obeying:
   - **Band:** 2400-3400w Grey Wolf, 2000-3400w Devouring Dragon, 2800 floor from ch3 Golden Lion — floor/ceiling enforced by measure_prose.py
   - **Style:** avg ≤25 (Grey Wolf perfect rebuild 14-18), no sentence >60 (cap later s43), ≥3 registers, dialogue mandatory in panels, dialogue floor e.g., ≥3 dialogue exchanges per scene, ≥3 spoken lines, 2,800-word floor from ch3, plain words, clean and clear no nonsense repetition (Grey Wolf law: show mastery via daily life action, lore dumps in footer only)
   - **Panels:** cold and quiet at key beats — and FULL status panel at every gate, but **F22 rule:** no full panel in chapter unless level/ring/bloodline update, beat 0 lines allowed, full details in STATUS.md SKILLS_CANON.md — e.g., Ch6 The Hem Road 0 panel lines daily life no fights yet effective talent 3.5x Spirit Sea 10-100m, show mastery via hem roads villages Grey Ridge Hunt using all basics MASTERED High
   - **Canon:** canon beats shown on page, OC beside them never on top, possession carding base-form card stack order ring-orbit exposure, soul beast not normal animal
   - **MCU:** no digits in prose, no CJK, no chapter footers, ASCII filenames, Talent never named embodied only, never replace canon cause participate protect preserve, never nerf deny ACCESS not competence, buffer+field ceilings hard

3. **SELF-AUDIT** — by hand against every law (25 laws). Small things become big things: wrong number in ch7 is continuity crisis in ch70. Fix own garbles before machine sees them — gate is safety net not editor. Human audit catches voice (does canon character sound like themselves? style-match ore notes), centering (did OC quietly take over canon moment? panel audit), earned bends (is butterfly caused by story so far or what I want next?). Plus check (d) date arithmetic every "N days ago / N days later" recomputed by hand against day map — highest-yield check caught 9 month-count errors in ch9 alone and 4 stale year counts in ch13.

4. **GATE** — run verify.py (or mcu_verify.py or run_all.sh battery). Must exit 0. If fails, fix chapter or update panel — never weaken gate to pass. Three rules of gates: 1) gate must selftest (10/10 defect classes caught on real ones, 5/5 on minigate), 2) never weaken gate to pass, 3) never trust only project's own checker (scanner hard-coded 11 SL4-specific firewall filenames so project declaring firewalls in differently-named file read as zero firewalls and reported PASS — happened, made generic after) — fix: independent drift scanner built on different assumptions side-by-side, two checkers disagree is most honest alarm. For Grey Wolf: tools/run_all.py = manuscript synced 6 reader+FULL + style gate passed + site built + panel ledger in sync + ledger rows 80 IN SYNC + band IN avg11.3-18.5 over60 0 the-way 0 bare 0. For Lan Shen: 9 layers ALL GREEN — verify, style_gate, canon_copy_check, marker-leak, privacy, hygiene, selftest, kit selftest, banned_token_check.

5. **SYNC** — same-turn: status panel (edge, ranks, locks), canon ledger (facts consumed, butterflies added), serial log (what happened this session), continuation prompt (what's next), chapter footer (gate receipt), plus every file after (codex, status, continuation, chapter footer, mirror, 00_INDEX.md, site, search_data, analytics, news, feed, calendar, profile). Use Everything Protocol: read all files → research canon primary → run every law/test → update every file after. Never "later". Ship script automates mechanical 80%: gates first, kit root README bump, serial README LIVE EDGE/NEXT BEAT swap (machine block markers <!-- LIVE-EDGE-START ... LIVE-EDGE-END --> wholesale block replace nothing stale survives), site chapter copied serials.json appended search_data rebuilt analytics rebuilt news+feed+calendar, profile bumped, sentinel re-run. Authored 20% deliberately not automated: STATUS_PANEL entry + LIVE EDGE line, HIS_STATUS_PANEL live line, ADAPTATION_LOG delta, SERIAL_LOG row, CONTINUITY row, PLACES/TIMELINE rows — checklist printed refuses "shipped" until --mirrors-done.

6. **SHIP** — commit with message that says what happened: `CH 3 SHIPPED — Monsters Run: ...` or `CH 6 SHIPPED — The Hem Road: ...`. Commit log becomes serial's heartbeat. Push via PAT (no workflow, REST for releases), re-export git identity every bash (standing instruction), gh absent REST. Tar not rsync.
