# 05 · Glossary

The vocabulary this method uses. Terms are fandom-neutral where possible; Soul Land examples in brackets.

---

**AT (Adaptation Talent)** — a protagonist trait that adapts/absorbs [my serials' signature OC power hook]. The reason the Unfixed Law exists: AT holders' state changes constantly, so every trait is recorded as a *dated state*.

**Banned values** — numbers/strings the prose may never state (usually superseded stats). Enforced by the gate's banned-value scan. Example: a stale project presented `Dawnflame 1,120` as current; the live panel banned that exact number.

**Butterfly** — a divergence from canon caused by the OC's presence. Every butterfly is *earned* (caused by the story so far) and *logged* (registry/ledger entry: cause, first divergence chapter, downstream effects).

**Canon ledger** — the running table of which canon facts each chapter consumed and which butterflies it introduced. A chapter without a ledger entry is an unaudited chapter.

**Canon spine** — the dated, sourced sequence of canon events the fic touches. The river your boat travels on.

**Control Centre** — a repo pattern where state lives in data files and everything human-facing (site, handoff text) is generated from them. You change the state, never the output.

**Drift** — the slow divergence between what the files say and what is true. Detected by drift scanners; prevented by same-turn syncing.

**Firewall (knowledge firewall)** — a rule stating what a character must not know yet, and the chapter from which they may learn it. Critical for reincarnator/regressor OCs who "know the future".

**Foundation** — the pre-prose docset (rails, rulings, spine, power law, firewalls, panel). Foundation-stage = rulings pending, drafting locked.

**Gate** — the checker that must exit 0 before a chapter ships. See the gate doc for the full anatomy.

**HANDOFF.md** — the cold-start brief that lets a brand-new collaborator (or AI agent) reach correct state in one read, without being told anything twice.

**Ledger footer** — the block at the end of every chapter: gate receipt, canon consumed, butterflies added.

**Live edge** — the exact point where the story currently stands ("after Chapter 52"). Claimed in the status panel, verified against disk by the gate.

**Lock** — a fact fixed by author ruling (identity, pairing, power cap). Locks outrank convenience.

**OC** — original character. The guest in canon's house: added, never centered.

**Ore** — raw canon material mined from primary text before drafting: extracts, indexes, style notes, good lines.

**Panel** — see status panel. Also: donghua-style panel cards used inside prose (the Multi-Panel Law: canon shown, never skipped).

**Ruling** — a numbered, dated decision by the author that outranks every file. Unanswered rulings lock drafting.

**Self-audit** — the human pass over a draft, against every law, before the gate runs. Machine for facts, human for truth.

**Selftest** — the gate's proof of competence: feed it known defects, demand it fires on every class. 10/10 on my real gates, 5/5 on the minigate example.

**Serial log** — append-only session diary: what happened, what was ruled, what synced.

**Status panel** — THE single source of truth for live state: edge, ranks, locks, bans, relationships, next chapter. Dated entries only.

**Two-Copies Law** — *a fact maintained in two places will be wrong in one of them, and the check reads the other.* The reason mirrors are banned or generated, and the reason the five-copies disaster got cleaned up.

**Verify** — to run the gate. "Verified" means exit 0, today, on this disk — not "I checked it once, a while ago."
