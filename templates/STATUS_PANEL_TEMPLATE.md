**Panel hygiene rules**

1. Version the panel (v1, v2…) — big reveals get a version bump.
2. Never edit history: supersede entries with new dated rows.
3. The gate reads this file: README live-edge claims must equal the highest chapter on disk.
4. One panel per serial. Never mirror it — Two-Copies Law.
