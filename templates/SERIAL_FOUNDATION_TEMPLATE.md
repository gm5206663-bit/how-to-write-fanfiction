# Serial Foundation Template

> Copy into `my_serial/foundation/` and fill in. **Drafting stays LOCKED until every ruling is answered.**

---

## README.md (serial root)

```
# <SERIAL NAME>

<Fandom> fan fiction — <era/branch>. OC: <name>, <power hook in one line>.

**Founded:** <date> · **Status:** FOUNDATION v1 (no chapters yet)
**Live edge:** before Chapter 1
**Lane:** canon entry at <canon ch N>; divergence policy: <follow canon by default / other>
**Read order:** HANDOFF.md → foundation/STATUS_PANEL.md → foundation/RAILS.md
```

## RAILS.md — the serial's laws of record

```
# RAILS
1. Canon-first: check canon before inventing; butterfly-check everything.
2. Canon shown, never skipped; the OC is added, never centered.
3. Traits are dated states; power is a baseline, never a ceiling.
4. Nothing pre-decided; bends only when earned + logged.
5. One source of truth (the status panel); no mirrors.
6. Plain language; dialogue floor: ≥3 exchanges per scene; word floor: <N>.
7. Author rulings outrank every file, including this one.
```
